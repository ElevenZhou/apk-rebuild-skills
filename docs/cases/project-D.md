# 案例：项目 D（Meowdoku 1.18.0 → PawStar）

| 项 | 内容 |
|---|---|
| 原包 | Meowdoku 1.18.0 XAPK（猫咪主题 Star Battle 解谜），Godot 4.x，脚本加密 |
| 状况 | 原团队离职，源码与 release keystore 均未交接；原包仍在商店上架 |
| 路线 | R3 纯重做；逆向产物只用作资产来源 + 契约来源 + 对标锚点 |
| 交付 | Godot 4.6.3 新工程 + 签名试玩 APK（122MB，com.pawstar.game）真机通过 |

## 决策门结论
D1 纯重做 · D2 骨架等价脸面不同 · D3 新包名（keystore 丢失）· D4 占位 + AB · D5 连击条/图鉴/闪电局 · D6 PawStar · D7 AB 默认全关

## 关键经验
1. 方案迭代了 3 版，每版都是因为一个前提被推翻（源码确认丢失 → 原包仍在架）。**前提要尽早向负责人求证。**
2. Ogg 重封装的 CRC 查表顺序错误，单字节测试测不出来，多字节才暴露。
3. headless 冒烟漏掉了信号连接失败 → 冒烟规则增加 grep `nonexistent`。
4. 跨月 streak 断签：日期差不能用月×31 近似。
5. 真机采证：ADB 硬点适合短流程；结算/广告用"用户录屏 + 帧差抽帧 + 视觉模型"效率高得多。
6. Android 导出最大的坑：ETC2/ASTC 没开时导出失败但错误列表为空，最后靠读 Godot 源码定位；中文路径也会导致多处静默失败。

## 遗留
首页打卡卡副标题被遮挡；对局页"看广告"按钮轻微压边；Spine 动画仍为降级版；Windows 包未做。
