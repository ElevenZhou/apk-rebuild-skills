# 项目 I：Godot资源回导命名碰撞复盘

本页只记录通用工具问题，不含产品包、素材、客户身份、账号或解包代码。

## 现象与根因

在macOS大小写不敏感目标盘上，两个源纹理的恢复名仅大小写不同，批次报告显示659项成功，实际只有658张PNG。旧实现用大小写敏感Dictionary去重，与目标文件系统语义不一致。报告成功不等于目标独立存在。

## 修复

目标名按小写查重/登记；首次冲突追加原hash，二次冲突继续编号。ctex解码并重编码PNG应标OK_RECOMP，不等同于源文件字节相同。源安装包和原纹理不修改。

## 验证

修复后同批659输入得到659张独立PNG，逐个回读、尺寸与目标存在检查通过。最小样例含仅大小写不同的两张纹理，旧版会覆盖，修正版保留两份。另验证重复短hash时追加序号。Godot4.6.1 CLI与skill lint通过。

## 其他经验与范围

Godot启动图只支持PNG，SVG图标需要先渲染。JSON反序列化可能把整数变成浮点；游戏状态指纹需要统一整数表现。两点已在项目本地处理，未改总流程或门禁。发布仍由人执行，本修复只涉及通用导出工具。
