# Debug 速查（按症状索引）

## 通用排查方法（按顺序）

1. **先复现再动手**：拿到稳定复现命令（headless 命令 / adb 序列），写进待优化清单。
2. **最小化**：新建最小项目 / 最小输入，剥离"项目本身"变量。项目 D 的 Android 导出问题就是靠"最小项目也失败"确认是环境问题。
3. **二分**：一次只改一个变量（路径、配置三元组、字段），每次都记录结果。
4. **错误文案为空时读源码**：工具报"有错误"但不给文案 → 去对应开源工具源码找 `valid = false` / `return false` 而没有 `add_message` 的分支。
5. **改用能看到错误的通道**：headless 吞掉的错误，用 debug 导出、verbose、GUI 编辑器、诊断脚本换通道看。
6. **修复后补回归**：每个修好的 bug 补一条测试或冒烟 grep 规则。

## 症状表

| 症状 | 首查 | 实例（项目） |
|---|---|---|
| headless 冒烟过了但真机功能失效 | stderr 里 grep `nonexistent`（信号连接失败类） | PanelContainer 没有 pressed 信号（D） |
| Parse Error 指向奇怪行号 | 上一行被脚本合并/转义坏了（Python 改代码的 `\n` 陷阱） | if 两行并成一行（D） |
| 某 API "不存在" | 该类型不支持 lambda/链式，如 PackedStringArray.map | YAML 解析器（D） |
| 跨月/跨年日期逻辑错 | 日期差用儒略日/ordinal，不要用 月×31 近似 | streak 跨月断签（D） |
| 测试首次过、复跑挂 | 测试间存档/持久化状态污染，setup 要彻底重置 | m3 跨日测试（D） |
| 导出失败但错误列表为空 | 读导出插件源码找无文案失败点 | Godot ETC2/ASTC 未开（D，见 engines/godot.md） |
| 导出/写文件静默失败 | **路径含中文**——工具链全部挪到纯 ASCII 路径 | Godot 导出、OpenCV imwrite（D） |
| `adb install` 报无证书 | 签名配置未生效（release 未签名） | keystore 三元组被清空（D） |
| ADB tap 没反应 | 坐标用像素定位而不是目测；注意状态栏偏移；双击窗口约 250ms | D |
| 视觉模型读数前后不一致 | 用像素采样交叉验证；渐变色区域分类靠交互反馈验证而非截图 | 区域矩阵反推失败（D） |
| 下载大文件反复中断 | 换镜像探测；后台下载；官方仓库 XML 查真实文件名 | Godot 模板、build-tools `r36` 命名（D） |

**新增症状**：项目中遇到不在表里的坑，修好后当天在这里加一行（症状 / 首查 / 实例），收尾时一起 PR。
