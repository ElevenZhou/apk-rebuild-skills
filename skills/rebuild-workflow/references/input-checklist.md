## 环境前置（执行人自查，开工前确认一次）
- 工具链放**纯 ASCII 路径**；`JAVA_HOME` 不能含中文。
- `java -version` 在当前 shell 可用；不可用时所有 Java 工具（apktool、jadx、sdkmanager）**显式指向 JDK 的 java.exe**——否则 apktool.bat 会静默卡死、没有任何输出。
- 哈希统一用 `sha256sum <文件>`（Git Bash / Linux / macOS 通用）；不要依赖 PowerShell 回显（部分 Agent 环境不回显）。

## 与既有项目门禁的关系
项目若已有更严格的门禁（如旧工单要求"P0 清零才能进下一阶段"），**以更严格者为准**；放宽必须由负责人书面决定，并记入 scope.md。
