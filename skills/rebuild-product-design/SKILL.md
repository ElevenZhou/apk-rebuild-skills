# rebuild-product-design — 产品定义（方案 / 决策 / 品牌 / 微创新 / 计划）

## 何时用 / 何时不用
- **用**：S2 文档已完成，开工写代码之前；或项目中途前提变化（如发现原包仍在架、keystore 丢失）需要重新过门。
- **不用**：纯资源修补、不涉及产品形态的小改。

## 需要的输入
docs/01-09（尤其 01 概述、02 功能、03 接口、09 复核清单）、scope.md、负责人对品牌和差异化的初步意向。

## 产物（全部放项目根目录，命名固定）
| 文件 | 内容 | 模板 |
|---|---|---|
| `重建方案-v#.md` | 目标 G1-Gn、路线、分层重建清单、风险、**决策门记录** | `references/plan-template.md` |
| `产品文档.md` | 新产品的功能规格（按模块）：保留什么、改什么、新增什么、删什么 | `references/prd-template.md` |
| `开发计划.md` | M0-M5 里程碑：内容、出口标准、依赖、估时（标 ⚠️估算） | 方案模板 §6 |
| `rebuild/branding/` | 命名报告、logo 横/竖/方三版、色板 | 见下文"品牌" |

## 步骤
1. **起草方案 v1**：按模板写目标与路线。路线三选一：
   - R1 原位恢复（找回源码/原 keystore，在原工程上修）
   - R2 部分逆向（脚本可还原，逻辑复用）
   - R3 纯重做（逆向产物只当"资产来源 + 契约来源 + 对标锚点"）
2. **过决策门 D1-D7**（每门：选项 → 推荐 → 理由 → 负责人结论）。**Agent 必须逐门停下来等确认，不能代替负责人拍板。**

   | 门 | 问题 | 典型选项 | 项目 D 结论 |
   |---|---|---|---|
   | D1 | 逆向深度 / 路线 | R1 / R2 / R3 | R3 纯重做（源码确认丢失） |
   | D2 | 差异化程度 | 像素级复刻 / 骨架等价脸面不同 / 大改 | 骨架等价脸面不同（原包仍在架） |
   | D3 | 包名 | 原包名更新 / 新包名 | 新包名（原 keystore 丢失） |
   | D4 | 数值口径 | 真机采证还原 / 占位 + AB 调平 | 占位 + AB |
   | D5 | 微创新点 | 2-3 个低耦合点 | 连击条 / 图鉴 / 闪电局 |
   | D6 | 品牌 | 沿用 / 新名新皮，何时定稿 | 新名 PawStar，M5 前定稿 |
   | D7 | AB 默认值 | 新功能默认开 / 关 | 全关，灰度开 |

3. **前提变化就升版本**：v1→v2→v3，每版开头写"本版修订了哪个前提"。决策改动 = 重新过门。
4. **写产品文档**：逐模块四列「保留 / 修改 / 新增 / 删除」，删除项必须包含 docs/07 的 cheat/debug 面。
5. **微创新**（见下）→ 写入方案 §4.5 与产品文档。
6. **品牌**（见下）→ 输出到 branding/。
7. **开发计划**：用 `rebuild-dev-milestones` 的 M0-M5 框架，按本项目内容填写，每个 M 写可验证的出口标准。
8. 负责人确认方案终版 → 锁定，进入 S5。

## 微创新的选择标准
- **低耦合**：只挂事件总线/结算钩子，或做成独立场景；**不改核心规则引擎**。
- **前端可见**：玩家一眼能感知到差异（用来拉开和原包的距离）。
- **复用现有素材**：优先用回导资源里没用上的动画/音效。
- **可 AB 开关**：每个点一个 AB 键（如 `catnip_combo`），默认关，灰度验证留存后再全量。
- 数量 2-3 个；每个写「内容 / 耦合面 / 复用素材 / AB 键 / 验证指标」。

## 品牌与换皮
- 命名：调研竞品命名 → 找空白定位 → 多语言发音检查 → 商标/商店重名检索 → 3-5 个候选给负责人选。（本机若装有 `game-brand-creator` skill 可直接用它出命名和 logo。）
- 视觉：logo 横/竖/方三版、应用图标、启动页、主色板；从参考截图提取色板，保证与原产品**可区分**。
- 换皮范围清单：名称、图标、启动页、主角形象、配色、文案中的品牌词、商店素材。
- 时机：开发期沿用回导素材，**M5 前定稿换皮**；换皮前的内测包不得外发。

## 出口标准
- D1-D7 全部有负责人结论并写入方案；
- 产品文档覆盖 docs/02 全部模块；
- 开发计划每个 M 有可验证出口标准；
- 方案风险表含"与原产品同质化"一项及缓解措施（若原包在架）。
